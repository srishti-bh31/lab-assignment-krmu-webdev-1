# ElegantStore – Responsive E-Commerce Website  
**Capstone Project**  
**Technologies Used:** HTML5, CSS3 (Flexbox + Grid), Responsive Design

##  Project Description  
ElegantStore is a modern, and fully responsive **E-Commerce Website** built using only **HTML5 and CSS3**.  
The project includes real-world components such as a hero banner, responsive product grid, filters sidebar, and a functional contact form.  
The layout follows semantic structure and good UI/UX practices.

##  Theme Chosen  
### **E-Commerce Store UI**  
Focus Areas:
- Product listing page  
- Sidebar filters  
- Responsive grid layout  
- Add-to-cart UI (static)  
- Clean and aesthetic modern design
