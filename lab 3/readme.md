Project Overview

This project is a one-page responsive personal portfolio website built using advanced CSS techniques. The website demonstrates modern layout principles using Flexbox, CSS Grid, media queries, relative units, animations, and hover effects.
It is designed to work smoothly on desktop, tablet, and mobile devices while maintaining a clean, professional, and visually appealing interface.

Features Implemented:-
1. Website Structure-
  Header
  Hero section
  About section
  Skills (Grid layout)
  Projects (Grid layout)
  Contact form
  Footer
2. Flexbox Usage-
  Header navigation layout
  Hero section arrangement (text left, image right)
  Buttons and content alignment
3. CSS Grid Usage-
  Skills section
  Projects gallery
4. Responsive Design-
  Mobile-first approach
  Breakpoints added for mobile, tablet, and desktop
  Hero image and text stack on small screens
  Grid sections collapse into single columns on mobile
5. Animations & Effects-
  Hover effects for links, buttons, and project cards
  Smooth CSS transitions
  Keyframe animations (e.g., color-changing text, fade-in elements)
  Transform effects on interactive elements
6. Typography & Colors-
  Google Fonts integrated
  Clean and modern font hierarchy
  Consistent color theme throughout website
  Technologies Used
  HTML5
  CSS3 (Flexbox, Grid, Media Queries, Animations)
  Google Fonts
  Font Awesome (optional for icons)
