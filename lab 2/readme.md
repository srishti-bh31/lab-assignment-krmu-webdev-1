Objective
Create a personal portfolio webpage using an external CSS stylesheet with a consistent color theme, custom typography, and structured layouts.
The project demonstrates skills in selectors, color theory, the box model, positioning, and visual design.
Project Overview
This webpage builds upon Lab 1 (HTML structure) and applies modern CSS techniques to achieve a professional look.
It includes sections such as Header, About, Projects, Skills, and Contact, styled with pinks,yellows, oranges and purples , rounded corners, and elegant shadows.
 Key Features
 Consistent Color Theme –  using HEX and RGB values.
 Custom Typography – Google Font Poppins for a clean and modern look.
 Box Model – Proper use of padding, margin, and borders for spacing.
 Sticky Navigation Bar – Styled header with hover transitions.
 Styled Skills Table – Smooth single border with alternating row colors.
 Contact Form – Polished inputs and buttons with border-radius and hover effects.
 Positioning Techniques –
 position: sticky → Header
 Visual Polish – <hr> separators, shadows, and consistent structure.
